# Project 1

Project for **COP 1047C** at Miami Dade College.

## Description

This Python program provides a menu for calculating:

- Powers (`base^exponent`)
- The exponential function (`e^x`)
- The sine of an angle in degrees (`sin(x)`)

The `e^x` and sine calculations use mathematical series with between 1 and 50 terms. Each term and result is displayed on the screen and saved to `output.txt`.

## Requirements

- Python 3
- The standard `math` library, included with Python

## How to Run

From the project folder, run:

```bash
python3 Project1.py
```

Then select an option from the menu and enter the requested values.

## Menu Options

1. Power Function
2. `e^x`
3. Sine
4. Quit

## Files

- `Project1.py`: the program's source code.
- `output.txt`: automatically generated file containing the calculated terms and results.
